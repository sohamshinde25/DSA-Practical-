# DSA Practical Programs

A collection of Data Structures and Algorithms practical implementations written in **C++**.

This repository contains practical programs covering searching, sorting, stacks, queues, graph algorithms, greedy algorithms, and string matching.

## 📚 Programs Included

| No. | Program | Filename |
|---|---|---|
| 01 | Student Search | `01_student_search.cpp` |
| 02 | Student Sorting and Comparison | `02_student_sort_compare.cpp` |
| 03 | Stack Infix Conversion | `03_stack_infix_conversion.cpp` |
| 04 | Circular Queue | `04_circular_queue.cpp` |
| 05 | Kruskal's Algorithm | `05_campus_kruskal.cpp` |
| 06 | Prim's Algorithm | `06_campus_prim.cpp` |
| 07 | Merge Sort on Orders | `07_merge_sort_orders.cpp` |
| 08 | Fractional Knapsack | `08_fractional_knapsack.cpp` |
| 09 | Naive String Matching | `09_naive_string_matching.cpp` |

## 🛠️ Technologies Used

- **Programming Language:** C++
- **Compiler:** GCC / G++
- **Operating Systems:** Linux / macOS
- **Editor:** VS Code

## 🚀 How to Run

**1. Clone the repository**

```bash
git clone https://github.com/sohamshinde25/DSA-Practical.git
```

**2. Navigate to the project directory**

```bash
cd DSA-Practical
```

**3. Compile a C++ program**

```bash
g++ 01_student_search.cpp -o program
```

**4. Execute the program**

```bash
./program
```

You can replace the filename with any other program in the repository.
